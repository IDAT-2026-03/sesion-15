TEMA 1

Pseudo-clases de Estado (:hover, :focus, :active)

Sintaxis: un solo dos puntos ( : )

Una pseudo-clase selecciona un elemento solo cuando se encuentra en un estado dinámico temporal provocado por la interacción del usuario.

:hover: Se activa cuando el puntero del mouse se sitúa encima del elemento. Indispensable para botones, enlaces y tarjetas.
:focus: Se activa cuando un elemento recibe el foco interactivo (clic en un <input> o navegación con tecla Tab). ¡Clave para accesibilidad!
:active: Se activa en el instante milimétrico que el usuario mantiene presionado el botón del mouse.
Código CSS
/* Estado normal */
.btn-contacto {
background-color: #111827;
color: #ffffff;
transition: all 0.25s ease; /* Suaviza el cambio */
}
/* Estado hover (mouse encima) */
.btn-contacto:hover {
background-color: #FFC820;
color: #111827;
}
/* Estado focus (cursor activo en campo) */
input:focus {
outline: 3px solid #FFC820;
}
Regla de Oro: Nunca elimines el outline con `outline: none` sin proveer un `:focus` visible alternativo. WCAG 2.2 Accesibilidad
EJEMPLO 1

Interacción en Vivo: :hover y :focus

Prueba la interactividad en el panel de la derecha. Observa cómo cambia la apariencia al interactuar con el mouse o al usar la tecla Tab.

Botón con :hover y :active: Pasa el cursor por el botón: cambia de fondo negro a amarillo IDAT. Al hacer clic sostenido, se encoge suavemente con transform: scale(0.96).

input {
  border: 2px solid #D1D5DB;

  color: #111827;

}
TEMA 2

Pseudo-elementos (::before y ::after)

Sintaxis: dos dobles puntos ( :: )

Un pseudo-elemento crea un elemento virtual decorativo en el árbol de renderizado del navegador sin necesidad de escribir etiquetas adicionales en el HTML.

::before: Inserta un hijo virtual inmediatamente antes del contenido real del elemento.
::after: Inserta un hijo virtual inmediatamente después del contenido real del elemento.
⚠️ La regla sagrada: Es 100% obligatorio incluir la propiedad content: "";. Si no declaras content, el pseudo-elemento no existirá en pantalla.
Sintaxis Oficial CSS3
/* Agrega icono antes del título */
.titulo-seccion::before {
content: "📌 "; /* ¡Propiedad obligatoria! */
}
/* Inserta una etiqueta decorativa después */
.producto-nuevo::after {
content: "TOP VENTAS";
font-size: 10px;
background-color: #FFC820;
color: #111827;
padding: 2px 6px;
border-radius: 4px;
margin-left: 8px;
}
Diferencia clave: Pseudo-clase (:hover) = estado | Pseudo-elemento (::after) = elemento cosmético virtual. Estándares W3C
EJEMPLO 2

Efectos Visuales con ::before y ::after

Mira el panel derecho: el HTML contiene únicamente texto plano, pero CSS inyecta insignias, viñetas doradas y barras laterales automáticamente.

Cinta lateral con ::before: Se crea un rectángulo vertical absoluto con content: '' y fondo #FFC820 sin tocar el marcado HTML.
Insignia automática con ::after: Añade un distintivo verde " [NUEVO]" a cualquier producto que tenga la clase .destacado.

TEMA 3

Cálculo de Especificidad y Prioridades

La Balanza: (Inline, ID, Clase, Etiqueta)

¿Qué ocurre cuando dos reglas CSS intentan pintar el mismo elemento con colores distintos? El navegador calcula un vector de peso (A, B, C, D):

1000 Pts Estilos Inline style="..."
100 Pts IDs #menu-principal
10 Pts Clases / :hover .card, :focus
1 Pto Etiquetas / ::before p, h1, div
p (1 etiqueta) Peso: 0, 0, 0, 1 = 1 pt
.btn.activo (2 clases) Peso: 0, 0, 2, 0 = 20 pts
#header .nav li a:hover (1 ID + 2 Clases/Pseudo + 2 Etiquetas) Peso: 0, 1, 2, 2 = 122 pts ⭐ GANA
⚠️ !important rompe la cascada natural: úsalo solo para resolver emergencias extremas. Regla de Desempate: A igual peso, gana la regla escrita más abajo en el archivo CSS.

Taller Integrador: Tarjeta Interactiva con CSS Puro

Construye una ficha de producto integrando los conceptos de la Sesión 14 (Box Model, bordes, tipografía) y la Sesión 15 (Pseudo-clases y Pseudo-elementos):

Paso 1 (Box Model): Aplica padding: 24px, border-radius: 20px y sombra suave al contenedor.
Paso 2 (Pseudo-elemento ::before): Agrega una franja dorada superior decorativa en la cabecera con content: '' y altura 6px.
Paso 3 (Pseudo-clase :hover): Al pasar el mouse, la tarjeta debe elevarse sutilmente con transform: translateY(-4px) y cambiar de sombra.
Paso 4 (Pseudo-clase :focus): El botón de compra debe encender un anillo dorado visible al recibir foco con teclado.
